# alu-scripting

ALU scripting and API projects.

## Directories

### [api_advanced](./api_advanced)

Advanced API scripting tasks.

- [0-subs.py](./api_advanced/0-subs.py) — `number_of_subscribers(subreddit)`: returns a subreddit's total subscriber count via the Reddit API, or `0` if invalid.

### [regular_expressions](./regular_expressions)

Ruby regular expression exercises.

Requirements:

- Python 3 and `requests` for the API tasks
- Ruby for the regular expression tasks
